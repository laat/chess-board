<chess-board>

A web component that renders a chess position. Put a FEN string between the tags and get a board. No framework, no stylesheet to load, one small dependency. 

$ npm install chess-board
Open the playground View on GitHub
  • Standards only. A plain custom element with shadow DOM.
  • Typed. Ships TypeScript declarations for the element, squares and pieces.
  • Scriptable. Move, place and clear pieces from JavaScript.

Quick start

Install, import, write markup. The element registers itself on import.

  1. Install

    The package is plain ES2022 with a single runtime dependency, fen-chess-board.

    $ npm install chess-board

  2. Import once

    Importing the module registers the <chess-board> element. Do it once, anywhere in your app.

    import "chess-board";

  3. Write markup

    The text content is the position. The piece-placement field of a FEN string is enough; the rest is ignored.

    <chess-board>
  rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR
</chess-board>
No bundler? Copy both packages into your static files and map the bare specifier with an import map. The readme has the snippet.

    Sizing
    
        
    
          The host is display: inline-block and every square is one em,
          so a board goes wherever text goes and scales with font-size.
        
    
      
    
      
    

      
    
        
    
          
    
            A diagram can sit right in a sentence, like this
            r1bqkb1r/pppp1Qpp/2n2n2/4p3/2B1P3/8/PPPP1PPP/RNB1K1NR
            one, and the line height stretches to fit. Handy for annotations, commit messages rendered as HTML,
            or a puzzle list where every row shows its position.
